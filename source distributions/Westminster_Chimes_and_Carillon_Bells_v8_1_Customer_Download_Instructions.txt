Westminster Chimes and Carillon Bells v8.1
Customer Download and Flash Drive Setup Instructions

Download page:

https://github.com/tmartindub/Carillon8_1/releases/tag/v8.1-portable

Overview

This is the portable flash drive version of Westminster Chimes and Carillon
Bells v8.1. The program is designed to run from the root of a USB flash drive.
Do not move Carillon.exe away from the folders that come with it.

The download is split into three ZIP files because the complete package is too
large for one GitHub download file.

Files to download

Download all three of these ZIP files:

1. Westminster_Chimes_and_Carillon_Bells_v8_1_Portable_1_Core.zip
2. Westminster_Chimes_and_Carillon_Bells_v8_1_Portable_2_Songs_A.zip
3. Westminster_Chimes_and_Carillon_Bells_v8_1_Portable_3_Songs_B.zip

The download manifest is optional, but useful for verifying the package:

Westminster_Chimes_and_Carillon_Bells_v8_1_Portable_Download_Manifest.txt

What you need

- A Windows computer.
- A USB flash drive with at least 8 GB free.
- All three ZIP files downloaded from the release page.
- Enough temporary space on the computer to hold the downloaded ZIP files.

Recommended flash drive preparation

1. Insert the USB flash drive.
2. Open File Explorer.
3. Note the drive letter Windows gives the flash drive, such as E: or F:.
4. If this is a new setup, use an empty flash drive.
5. If this is an existing Carillon flash drive, back it up before replacing
   anything.

Important upgrade warning

The package includes a database in the databases folder. Replacing an existing
database may replace your existing schedule and settings. If you already use
Carillon and are upgrading an existing flash drive, back up the old flash drive
first and do not overwrite your database unless you intend to replace it.

How to extract the files

1. Create or choose a temporary folder on your computer, such as Downloads.
2. Put all three downloaded ZIP files in that folder.
3. Right-click Westminster_Chimes_and_Carillon_Bells_v8_1_Portable_1_Core.zip.
4. Choose Extract All.
5. When Windows asks where to extract it, choose the root of the USB flash
   drive, such as:

   F:\

6. Extract the first ZIP file.
7. Repeat the same process for
   Westminster_Chimes_and_Carillon_Bells_v8_1_Portable_2_Songs_A.zip.
8. Extract it to the same USB flash drive root, such as:

   F:\

9. If Windows asks whether to merge folders, choose Yes.
10. Repeat the same process for
    Westminster_Chimes_and_Carillon_Bells_v8_1_Portable_3_Songs_B.zip.
11. Extract it to the same USB flash drive root.
12. If Windows asks whether to merge folders, choose Yes.

The logs folder is included empty. Carillon creates the play log when needed.

How to start Carillon

Best method:

1. Open the flash drive in File Explorer.
2. Double-click start_carillon.vbs.

Alternate methods:

- Double-click start_carillon.bat.
- Double-click carillon.bat.
- Double-click Carillon.exe from the root of the flash drive.

Important launch rule

Carillon must be started from the flash drive root. The program expects to find
its database and folders on the same flash drive. If you start it from a command
prompt, first switch to the flash drive and then run the program. Example:

F:
Carillon.exe

If your flash drive is E:, use:

E:
Carillon.exe

Do not copy Carillon.exe by itself to the desktop or another folder. It needs
the folders on the flash drive.

Troubleshooting

Problem: Carillon says it cannot open the database.

Cause:
The program was probably started from the wrong working folder, or Carillon.exe
was moved away from the flash drive root.

Fix:
Open the flash drive in File Explorer and run start_carillon.vbs from the flash
drive root. Do not run a copied Carillon.exe from another folder.

Problem: Songs are missing or do not play.

Cause:
One or more ZIP files were not extracted, or they were extracted to the wrong
location.

Fix:
Make sure all three ZIP files were extracted to the same flash drive root. The
flash drive should contain the Songs, Music, Random_songs, and Random_songs-2
folders.

Problem: The logs folder is empty.

This is normal. Carillon creates the log file when it needs one.

Problem: Windows blocks or warns about the downloaded files.

Cause:
Windows may warn about files downloaded from the internet.

Fix:
Make sure the files came from the official GitHub release page. If Windows shows
a normal security prompt, allow the program to run only if you trust the source.

Problem: The program opens, but schedule or music paths do not work.

Cause:
The flash drive contents may not be in the root of the drive.

Fix:
Check that Carillon.exe is directly on the flash drive, for example:

F:\Carillon.exe

It should not be inside an extra folder such as:

F:\Westminster_Chimes_and_Carillon_Bells_v8_1_Portable_1_Core\Carillon.exe

Correct folder layout

Correct:

F:\Carillon.exe
F:\databases\carillon.db
F:\Songs
F:\Music
F:\Random_songs
F:\Random_songs-2

Incorrect:

F:\Some Folder\Carillon.exe
F:\Some Folder\databases\carillon.db

After setup

Once the program starts successfully, keep the flash drive folder layout intact.
The program, database, help files, logs folder, and song folders work together
as one portable package.
